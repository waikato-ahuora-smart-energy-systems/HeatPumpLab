Steam-generating heat pump

Single-stage cycle with an internal heat exchanger and a hot-water subcooler. The condenser raises steam from bled hot water. Set the source, steam and hot-water temperatures, the refrigerant mix and compressor speed, and the cycle re-solves with CoolProp. Save cases, compare up to four side by side, and run sweeps.

Python package

Open source, Apache-2.0

The apps are ports of the cycle models in the HeatPumpLab Python package, which adds design optimisation, REFPROP support and the full test suite. Install it from the GitHub repository with uv sync.

The live models use CoolProp compiled to WebAssembly and run entirely in your browser; nothing you enter is sent anywhere.
